# 정신병자 · 질환의 형태

neighbors-site의 인터랙티브 타이틀(‘정신병자’ 타이포 + 16개 질환 막대)만 가져와 만든 새 작업. 원본 저장소·배포본은 수정하지 않았다.

흐름: 막대 고르기 → 색 막대와 관련어 → 한 번 더 누르면 형태 변화 → 같은 윤곽의 3D 형태로 오버랩 → 3D와 설명 패널만 남음. Esc 또는 ‘← 타이틀로’로 돌아간다.

- `index.html` · `style.css` — 화면 구성
- `stage.js` — 2D 타이틀·막대·형태 변화 (원작 life.js에서 가져와 축소)
- `viz.js` — Three.js 3D 시각화와 설명 패널
- `data.js` — 질환별 수치(출처)와 VAD 추정값·개념 설명
- `vendor/` — three.js r160 (빌드 없이 동작하도록 동봉)

실행: 폴더에서 `python3 -m http.server` 후 http://localhost:8000 (모듈 스크립트라 파일을 더블클릭하면 3D가 뜨지 않는다).
원작의 종이 배경(`paper.png`)을 `assets/paper.png`에 넣으면 자동으로 그 이미지를 쓰고, 없으면 같은 성격의 글자 층을 그린다.
